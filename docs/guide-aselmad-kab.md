# Amnir n uselmad – Tafat

Amnir-a yessegzay amek ara tesqedceḍ **Tafat Master** deg tesragt. I usebded
n texxamt, ẓer [install.html](install.html) neɣ [DEPLOYMENT.md](DEPLOYMENT.md).

> Arewway (draft): yettwaru s tmaziɣt (tiqbaylit, isekkilen ilatiniyen) seg
> umnir s tefransist ([guide-enseignant.md](guide-enseignant.md)). Ismawen n
> tqeffalin d wid n tsuqilt n tura (`translations/tafat_kab.ts`,
> `veyon_kab.ts`); ad beddlen ma yettwaseɣti tsuqilt. Ttxil-wet, ssefhem-d
> tuccḍiwin.

## 1. Bdu

1. Ldi **Tafat Master** ɣef uselkim n uselmad.
2. Fren taxxamt s **Tixxamin & iselkimen** (ukessar, ɣer zelmeḍ). Yal tagnit
   tesskan agdil n yiwen unelmad. Tagnit tazeggaɣt-tazegzawt (taɣlayt): aselkim
   yensa neɣ Tafat ur yeddi ara fell-as.
3. Fren iselkimen s yiwen usiti (Ctrl + asiti i wugar). Ma ur tefriḍ yiwen,
   tigawt teddu ɣef **yal** aselkim i d-yettbanen.

Aselkim amaynut n unelmad? Sebded-it s **Amsebded n yinelmaden** (ɣef tsarut
USB, sit snat n tikkal ɣef uselkim n unelmad), syin **Rnu iselkimen** →
**Nadi** → ṛcem-it → **Rnu ɣer texxamt**. **Iɣewwaren** yeldi asmesbadu
(tutlayt, d wayen nniḍen); *OK* ad isekles syin ad imdel.

Akken ad yili ugar n wadeg i tegniwin: taqeffalt deg teɣmert n wadda (*Ffer
afeggag n yifecka*) teffer afeggag n tqeffalin, taqeffalt-nni kan ad t-id-terr.
Mi yella yeffer, asiti ayeffus deg temnaḍt n yiselkimen yefka-d akk timahilin.
Asiti ayeffus ɣef ufeggag → *Sken tignitin kan* yesseḥzay-it.

## 2. Tazwara n tesragt: tilin

- **Tilin**: yal anelmad yettaru isem-is d tneɣrit-is. Ismawen-nsen ad d-banen
  ɣef tegniwin, ula ma yal inelmaden sseqdacen yiwen n umiḍan Windows.
- Deg usfaylu n tilin, kter tabdart n tneɣrit (afaylu CSV n tfelwit n
  uɣerbaz): inelmaden **ixuṣṣen** ad d-banen s uzeggaɣ.
- *Sifeḍ (CSV)* yessekles tilin (yeldi deg Excel neɣ LibreOffice).

## 3. Wali, ɛiwen

| Taqeffalt | I wacu |
|---|---|
| **Aɛessi** | tamuɣli tamagnut n yigdilen |
| **Tamuɣli s lebɛid** | semɣer agdil n yiwen unelmad |
| **Asenqed s lebɛid** | ṭṭef afus n uselkim akken ad tɛiwneḍ |
| **Asemɣer** | sken kan iselkimen yettwafernen |
| **Tuṭṭfa n ugdil** | sekles agdil n unelmad |

## 4. Sken, jbed lwelha

- **Askan**: sken agdil n uselmad s ugdil aččuran neɣ deg usfaylu.
- **Sekkeṛ**: igdilen ttuɣalen d iberkanen, anasiw d tɣerdayt ttwasekkṛen;
  sit tikkelt nniḍen akken ad ten-teldiḍ.
- **Izen aḍris**: sken aḍris awezlan ɣef yigdilen.
- **Ldi asmel web** / **Senker asnas**: ldi yiwen usmel neɣ yiwen wahil ɣef
  yal inelmaden.

## 5. Sewḥel

- **Sewḥel isnasen**: yessewḥal ihilen n tebdart neɣ yessireg *kan* wid n
  tebdart (amedya `winword`, `excel`). Tiqeffalin *Rnu iminigen web* d
  *Rnu ihilen n tnarit* ččarent tabdart. Deg Windows: sewḥel daɣen
  **tisura USB** d **usiggez**.
- **Isnasen yeldin**: wali isnasen yeldin ɣef yal aselkim, seg melmi, d wid
  yettwasqedcen syin mdlen; mdel asnas ɣef yiwen neɣ ɣef yal iselkimen.
- **Sewḥel ismal**: tabdart n yismal yettwagedlen, neɣ kan ismal yettwasirgen,
  i Chrome, Edge, Brave, Chromium d Firefox (Firefox yesra ad yales asekker).
  Taxtiṛt *Sewḥel daɣen internet i yihilen nniḍen meṛṛa (Windows kan)* tegzem
  internet war ma tegzem aẓeṭṭa n texxamt.

Sit tikkelt nniḍen ɣef tqeffalt akken ad tekkseḍ asewḥel.

## 6. Ssekyed: akayad

1. **Akayad** → *Akayad amaynut* (neɣ *Asestan amaynut*), azwel, akud ma
   tebɣiḍ, syin *Rnu asteqsi*: *Afran asuf*, *Afran aget*, *Tiririt s
   uḍris* neɣ *Yeṣeḥḥa neɣ ur yeṣeḥḥa ara*. Yiwet n tririt deg yal izirig;
   sers `*` zdat n tririyin yeṣeḥḥan. War `*`, asteqsi d **asestan** (ulac tazmilt).
   *Tineqqiḍin* fkant azal ugar i yiwen usteqsi.
2. Fren akayad deg tebdart, syin sit ɣef *Senker*. Ma yella wakud, inelmaden
   ad walin amḍan i d-yettqeṛṛiben, tiririyin-nsen ad ttwaznent s timmad-nsent
   di taggara.
3. Igmaḍ ttawḍen-d imir-a (afeggag i yal tiririt, tazmilt i yal anelmad).
   *Sifeḍ (CSV)* yessekles-iten.

Tiririyin yeṣeḥḥan ur ttwaznent ara ɣer yiselkimen n yinelmaden.

## 7. Mmeslay: afus d udiwenni

- **Afus d udiwenni** → *Sken afeggag n unelmad*: yal anelmad ad yaf afeggag
  amecṭuḥ s **Rfed afus**, adiwenni d *Azen leqdic*. Aneccab deg taggara n
  ufeggag yesseḥzay-it ar ufus kan.
- Afus yettwarefden ad d-iban ɣef tegnit d usfaylu n udiwenni (*Ldi asfaylu n
  udiwenni*). Err i yiwen unelmad neɣ *Azen i yal yiwen*; *Sers afus* mi
  yefra.
- **Arrazen** → *Efk itri*: yal anelmad yettwafernen ad yaf itri, ad iwali
  "Ayuz!" d umḍan n yitran-is. *Kkes itri* yekkes yiwen. *Sken itran* yesskan
  itran n tneɣrit meṛṛa (s yismawen n tilin), s *Ales seg tazwara* d
  *Sifeḍ (CSV)*. Yal tasmilt ɣur-s itran-is: fren tasmilt deg uqerru n
  usfaylu (*Tasmilt tamaynut* akken ad ternuḍ yiwet), neɣ m ulac anelmad
  ad d-yernun ɣef yiwen uselkim ad iwali itran n win yezwaren. Asfaylu
  yettweldi deg yitri amezwaru n yal tamsirt.

## 8. Ifuyla

- **Bḍu**: azen ifuyla i yinelmaden.
- **Lqeḍ**: awi-d ifuyla n yinelmaden; yal anelmad ɣur-s akaram-is (isem n
  tilin + aselkim).
- Inelmaden zemren daɣen ad *Azen leqdic* s yiman-nsen seg ufeggag-nsen;
  *Ldi leqdic yettwaznen* deg usfaylu n udiwenni.
- **Err leqdic**: fren akaram n yifuyla yettwalqeḍen (amedya mbeɛd aseɣti);
  yal anelmad ad yeṭṭef ifuyla n ukaram-is.

## 9. Taggara n tesragt

- **Ffeɣ** seg tɣimiyin, **Sexsi**, **Ales asekker** neɣ **Sekker** (s
  uẓeṭṭa, ma yermed deg BIOS).
- **Asmiḍen**: lqem n Windows, amesduṛ, takatut, aḍebsi d lqem n Tafat n yal
  aselkim, yettwasifeḍ s CSV.

## 10. Ma yella wugur

- **Tagnit taɣlayt**: aselkim yensa, ur yelli ara deg uẓeṭṭa neɣ ameẓlu Tafat
  ur yeddi ara. Ales asekker n uselkim n unelmad.
- **Anekcum yettwagi**: aselkim n unelmad ulac ɣur-s tasarut n uselkim-a n
  uselmad. Snulfu-d tikkelt nniḍen **Amsebded n yinelmaden** syin sebded-it
  ɣef uselkim-a.
- **Asmel ur yettwasewḥel ara**: aminig ur yettwasefrak ara neɣ Firefox ur
  yales ara asekker; sewḥel aminig-a s **Sewḥel isnasen**.

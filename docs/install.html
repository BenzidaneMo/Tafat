Installer Tafat dans une salle informatique

Tafat est un logiciel libre et gratuit de gestion de classe pour les salles informatiques : voir et contrôler tous les écrans, bloquer applications et sites, faire des quiz, faire l'appel, discuter avec les élèves. En arabe, tamazight, français et anglais, sur Windows 7 à 11.

Pour la personne qui installe la salle : un poste enseignant et les postes des élèves dans le même réseau. Tafat s'installe d'abord sur le poste de l'enseignant ; il crée ensuite lui-même l'installeur des postes des élèves. Aucune commande à taper.

1. Programme d'installation 2. Poste enseignant 3. Postes élèves 4. Ajouter les postes 5. Vérifier 6. Réseau 7. Problèmes
État : les programmes d'installation sont construits automatiquement mais n'ont pas encore été essayés sur de vrais postes de salle. Merci de signaler tout problème.

1Choisir le programme d'installation

Il existe quatre programmes d'installation. Ils fonctionnent tous ensemble : un poste enseignant sous Windows 11 peut piloter des postes élèves sous Windows 7, et inversement.

Version de Windows du poste
Architecture
Programme à utiliser : Windows 11 n'existe qu'en 64 bits. Vérifiez l'architecture du poste. tafat-<version>-win64-setup.exe

Pour connaître la version et l'architecture : touches Windows + Pause, ou Windows + R puis winver.

WindowsProgramme d'installation
10 / 11, 64 bitstafat-<version>-win64-setup.exe
10, 32 bitstafat-<version>-win32-setup.exe
7 / 8.1, 64 bitstafat-<version>-win64-legacy-setup.exe
7 / 8.1, 32 bitstafat-<version>-win32-legacy-setup.exe

Le programme d'installation refuse de s'exécuter sur une version de Windows ou une architecture qui ne lui correspond pas. Téléchargez les fichiers .exe sur la page Releases. Les versions de développement, plus récentes, sont dans les builds Windows (fichiers zip tafat-windows-<arch>-qt6, et -qt5 pour Windows 7/8.1, compte GitHub nécessaire).

Windows 7 et 8.1

  • Windows 7 doit avoir le Service Pack 1. La mise à jour KB2533623 est recommandée ; sans elle, Ctrl+Alt+Suppr ne peut pas être envoyé à distance.
  • Le blocage des sites fonctionne avec les dernières versions pour Windows 7 : Chrome 109 et Firefox ESR 115.
  • Windows 7 ne reçoit plus de mises à jour de sécurité : gardez ces postes dans le réseau de la salle, de préférence sans accès direct à Internet.

2Poste de l'enseignant

  1. Lancez le programme d'installation sur le poste de l'enseignant et gardez tous les composants.
  2. À la fin, laissez cochée la case Démarrer Tafat Master maintenant et cliquez sur Fermer.
C'est tout : le programme d'installation crée la clé de l'enseignant et règle l'authentification. La clé privée reste sur ce poste ; seule la clé publique ira sur les postes des élèves.

La langue se règle dans Tafat Master → Paramètres → Général → Langue (arabe, français, tamazight en latin ou en tifinagh, anglais), puis OK.

3Postes des élèves

  1. Dans Tafat Master, cliquez sur Installeur élève. Si la salle a aussi des postes sous Windows 7/8.1 ou en 32 bits, cliquez sur Ajouter un programme d'installation… et choisissez le fichier correspondant (étape 1).
  2. Branchez une clé USB, cliquez sur Créer sur une clé USB ou dans un dossier… et choisissez la clé. Elle reçoit par exemple Install Tafat - student (Windows 10-11 64-bit).exe.
  3. Sur chaque poste élève : double-cliquez sur ce fichier, répondez Oui quand Windows demande l'autorisation, puis Suivant, Installer et Fermer.
L'installeur élève contient la clé publique et les paramètres du poste de l'enseignant : il n'y a rien d'autre à régler sur les postes des élèves. Refaites-le si vous changez de poste enseignant.

4Ajouter les postes à la salle

  1. Allumez les postes des élèves.
  2. Dans Tafat Master, cliquez sur Ajouter des ordinateurs. Donnez un nom à la salle, par exemple Salle informatique 1.
  3. Cliquez sur Rechercher : les postes où Tafat est installé apparaissent après quelques secondes. Pour un autre réseau, saisissez-le dans Réseau à parcourir (par exemple 192.168.2.0/24), ou ajoutez un poste avec son nom ou son adresse IP.
  4. Cochez les postes de cette salle, cliquez sur Ajouter à la salle et répondez Oui à Windows. Les postes s'affichent aussitôt dans Tafat Master.
Avancé : installation silencieuse et ligne de commande

Pour un outil de déploiement, l'installeur élève fonctionne aussi en silence : "Install Tafat - student (Windows 10-11 64-bit).exe" /S. Les programmes d'installation habituels acceptent ces options :

tafat-<version>-win64-setup.exe /S /NoMaster /ApplyConfig=D:\tafat-config.json /ImportPublicKey=D:\teacher_public_key.pem
OptionEffet
/Sinstallation silencieuse
/NoMastersans le programme de l'enseignant
/NoTeacherSetupne crée pas la clé de l'enseignant et ne change pas l'authentification
/NoInterceptionsans le pilote de périphériques d'entrée (sert à bloquer clavier et souris)
/NoStartMenuFolderpas d'entrées dans le menu Démarrer
/ApplyConfig=<fichier>importe une configuration exportée du configurateur
/ImportPublicKey=<fichier>importe une clé publique (remplace une clé du même nom)
/PublicKeyName=<nom>nom de la clé importée (par défaut teacher)
/D=<dossier>dossier d'installation (toujours en dernier)

Paramètres → Installation de la salle → Exporter l'installation des élèves… écrit les deux fichiers et un script install-students.bat qui choisit le bon programme d'installation (à lancer en tant qu'administrateur, programmes d'installation dans le même dossier).

Ligne de commande (dans une invite de commandes administrateur) :

"C:\Program Files\Tafat\tafat-cli.exe" labsetup setupteacher
"C:\Program Files\Tafat\tafat-cli.exe" labsetup createpackage tafat-<version>-win64-setup.exe E:\eleves.exe
"C:\Program Files\Tafat\tafat-cli.exe" networkobjects import computers.csv format "%location%;%name%;%host%"
Dans PowerShell, mettez & devant un chemin entre guillemets : & "C:\Program Files\Tafat\tafat-cli.exe" …. Sans lui, PowerShell affiche « Unexpected token ». Ou utilisez cmd.

Désinstaller : "C:\Program Files\Tafat\uninstall.exe" /S (ajoutez /ClearConfig pour supprimer aussi la configuration).

5Vérifier

  1. Dans Tafat Master, chaque poste allumé doit afficher l'écran de l'élève.
  2. Sélectionnez tous les postes puis Inventaire : chaque poste doit répondre avec la version attendue (les versions pour anciens systèmes sont signalées). Exporter en CSV… enregistre la liste.
  3. Essayez Verrouiller puis déverrouillez.

6Réseau

PortSurUsage
TCP 11100postes élèvesconnexion de l'enseignant (écrans, commandes)
TCP 11400poste enseignantdémo (écran de l'enseignant vers les élèves)
  • Le programme d'installation ajoute l'exception dans le pare-feu Windows. Les autres pare-feu de la salle doivent autoriser ces ports.
  • Des adresses IP fixes ou des réservations DHCP rendent la liste de la salle fiable.
  • Bloquer aussi Internet pour tous les autres programmes ne bloque que les adresses Internet publiques : le réseau de la salle continue de fonctionner.
  • Le blocage de l'impression arrête le service Spouleur d'impression des postes élèves pendant le mode ; il est rétabli ensuite.

Un site n'est pas bloquéNavigateur non pris en charge ou Firefox pas redémarré : bloquez ce navigateur avec Bloquer les applis.

Installing Tafat in a computer lab

Tafat is free, open source classroom management for school computer labs: see and control every screen, block apps and websites, run quizzes, take attendance, chat with students. In Arabic, Tamazight, French and English, on Windows 7 to 11.

For the person who sets up the lab: one teacher computer and the student computers on the same network. Tafat is installed on the teacher computer first; it then creates the installer for the student computers itself. No commands to type.

1. Installer 2. Teacher computer 3. Student computers 4. Add computers 5. Check 6. Network 7. Problems
Status: the installers are built automatically but have not yet been tried on real lab computers. Please report any problem.

1Choose the installer

There are four installers. They all work together: a teacher computer on Windows 11 can control student computers on Windows 7, and the other way round.

Windows version of the computer
Architecture
Installer to use: Windows 11 only exists as 64-bit. Check the computer's architecture. tafat-<version>-win64-setup.exe

To find the version and architecture: press Windows + Pause, or Windows + R and type winver.

WindowsInstaller
10 / 11, 64-bittafat-<version>-win64-setup.exe
10, 32-bittafat-<version>-win32-setup.exe
7 / 8.1, 64-bittafat-<version>-win64-legacy-setup.exe
7 / 8.1, 32-bittafat-<version>-win32-legacy-setup.exe

An installer refuses to run on a Windows version or architecture it is not made for. Download the .exe files from the Releases page. Newer development versions are in the Windows builds (zip files tafat-windows-<arch>-qt6, and -qt5 for Windows 7/8.1; a GitHub account is needed).

Windows 7 and 8.1

  • Windows 7 needs Service Pack 1. Update KB2533623 is recommended; without it, Ctrl+Alt+Del cannot be sent remotely.
  • Website blocking works with the last versions for Windows 7: Chrome 109 and Firefox ESR 115.
  • Windows 7 no longer gets security updates: keep these computers on the lab network, preferably without direct internet access.

2Teacher computer

  1. Run the installer on the teacher computer and keep all components.
  2. At the end, leave Start Tafat Master now ticked and click Finish.
That's all: the installer creates the teacher's key and sets up authentication. The private key stays on this computer; only the public key goes to the student computers.

To change the language: Tafat Master → Settings → General → Language (Arabic, French, Tamazight in Latin or Tifinagh script, English), then OK.

3Student computers

  1. In Tafat Master, click Student installer. If the lab also has Windows 7/8.1 or 32-bit computers, click Add installer… and choose the matching file (step 1).
  2. Plug in a USB stick, click Create on USB stick or folder… and choose the stick. It gets, for example, Install Tafat - student (Windows 10-11 64-bit).exe.
  3. On each student computer: double-click this file, answer Yes when Windows asks for permission, then Next, Install and Finish.
The student installer carries the public key and the settings of the teacher computer: nothing else needs to be set up on the student computers. Create it again if the teacher computer changes.

4Add the computers to the room

  1. Switch on the student computers.
  2. In Tafat Master, click Add computers. Give the room a name, for example Computer lab 1.
  3. Click Search: the computers with Tafat installed appear after a few seconds. For another network, type it in Network to search (for example 192.168.2.0/24), or add a computer by its name or IP address.
  4. Tick the computers of this room, click Add to the room and answer Yes to Windows. The computers show up in Tafat Master right away.
Advanced: silent installation and command line

For a deployment tool, the student installer also runs silently: "Install Tafat - student (Windows 10-11 64-bit).exe" /S. The plain installers accept these options:

tafat-<version>-win64-setup.exe /S /NoMaster /ApplyConfig=D:\tafat-config.json /ImportPublicKey=D:\teacher_public_key.pem
OptionEffect
/Ssilent install
/NoMasterwithout the teacher program
/NoTeacherSetupdoes not create the teacher key or change authentication
/NoInterceptionwithout the input device driver (used to lock keyboard and mouse)
/NoStartMenuFolderno Start menu entries
/ApplyConfig=<file>imports a configuration exported from the configurator
/ImportPublicKey=<file>imports a public key (replaces a key with the same name)
/PublicKeyName=<name>name of the imported key (default teacher)
/D=<folder>installation folder (always last)

Settings → Lab setup → Export student setup… writes these two files and an install-students.bat script that picks the right installer (run it as administrator, with the installers in the same folder).

Command line (in an administrator command prompt):

"C:\Program Files\Tafat\tafat-cli.exe" labsetup setupteacher
"C:\Program Files\Tafat\tafat-cli.exe" labsetup createpackage tafat-<version>-win64-setup.exe E:\students.exe
"C:\Program Files\Tafat\tafat-cli.exe" networkobjects import computers.csv format "%location%;%name%;%host%"
In PowerShell, put & before a quoted path: & "C:\Program Files\Tafat\tafat-cli.exe" …. Without it, PowerShell reports "Unexpected token". Or use cmd.

Uninstall: "C:\Program Files\Tafat\uninstall.exe" /S (add /ClearConfig to remove the configuration too).

5Check

  1. In Tafat Master, every computer that is switched on should show the student's screen.
  2. Select all computers, then Inventory: each computer should answer with the expected version (builds for older systems are marked). Export CSV… saves the list.
  3. Try Lock, then unlock.

6Network

PortOnUsed for
TCP 11100student computersteacher connection (screens, commands)
TCP 11400teacher computerdemo (teacher's screen to the students)
  • The installer adds the exception to Windows Firewall. Other firewalls in the lab must allow these ports.
  • Fixed IP addresses or DHCP reservations keep the lab's computer list reliable.
  • Also block the internet for all other programs only blocks public internet addresses: the lab network keeps working.
  • Print blocking stops the Print Spooler service on the student computers while the mode is on; it is restored afterwards.

7If something goes wrong

SymptomWhat to check
Grey tileComputer switched off, not on the network, or Tafat service stopped. Restart the computer; check port 11100.
"Could not modify the autostart property for the Tafat Service"The Tafat service is not installed (sc query TafatService reports 1060). In an administrator command prompt: "C:\Program Files\Tafat\tafat-cli.exe" service register, then … service start, or run the installer again.
Search finds no computersTafat is not installed on them, they are switched off or on another network, or a firewall blocks port 11100. Type the computer's name or IP address.
Access deniedThe computer does not have the key of this teacher computer. Create the student installer again in Tafat Master and run it on that computer.
"This version of Tafat requires Windows 10 or newer" or "This installer is for 64-bit Windows"Use the other installer (-legacy for Windows 7/8.1, win32 for 32-bit).
A website is not blockedBrowser not supported or Firefox not restarted: block that browser with Block apps.

تثبيت تافات في قاعة الإعلام الآلي

تافات برنامج حر ومجاني لإدارة القسم في قاعات الإعلام الآلي: مشاهدة كل الشاشات والتحكم فيها، حظر التطبيقات والمواقع، إجراء اختبارات، تسجيل الحضور، والتواصل مع التلاميذ. بالعربية والأمازيغية والفرنسية والإنجليزية، على Windows 7 إلى 11.

هذا الدليل موجّه لمن يجهّز القاعة: حاسوب الأستاذ وحواسيب التلاميذ في الشبكة نفسها. يُثبَّت تافات أولًا على حاسوب الأستاذ، ثم يُنشئ بنفسه برنامج تثبيت حواسيب التلاميذ. لا حاجة لكتابة أي أمر.

1. برنامج التثبيت 2. حاسوب الأستاذ 3. حواسيب التلاميذ 4. إضافة الحواسيب 5. التحقق 6. الشبكة 7. المشاكل
الحالة: برامج التثبيت تُبنى آليًا لكنها لم تُجرَّب بعد على حواسيب قاعة حقيقية. نرجو الإبلاغ عن أي مشكلة.

1اختيار برنامج التثبيت

توجد أربعة برامج تثبيت، وكلها تعمل معًا: يمكن لحاسوب أستاذ بنظام Windows 11 أن يتحكم في حواسيب تلاميذ بنظام Windows 7، والعكس.

إصدار Windows على الحاسوب
البنية
البرنامج المناسب: يوجد Windows 11 بنسخة 64 بت فقط. تحقق من بنية الحاسوب. tafat-<version>-win64-setup.exe

لمعرفة الإصدار والبنية: اضغط Windows + Pause، أو Windows + R ثم اكتب winver.

Windowsبرنامج التثبيت
10 / 11، 64 بتtafat-<version>-win64-setup.exe
10، 32 بتtafat-<version>-win32-setup.exe
7 / 8.1، 64 بتtafat-<version>-win64-legacy-setup.exe
7 / 8.1، 32 بتtafat-<version>-win32-legacy-setup.exe

يرفض برنامج التثبيت العمل على إصدار Windows أو بنية لا تناسبه. حمّل ملفات .exe من صفحة الإصدارات (Releases). نسخ التطوير الأحدث موجودة في بناءات Windows (ملفات zip باسم tafat-windows-<arch>-qt6، و-qt5 لـ Windows 7/8.1، يلزم حساب GitHub).

Windows 7 و 8.1

  • يحتاج Windows 7 إلى حزمة الخدمة Service Pack 1. يُنصح بالتحديث KB2533623؛ بدونه لا يمكن إرسال Ctrl+Alt+Del عن بعد.
  • يعمل حظر المواقع مع آخر الإصدارات المتاحة لـ Windows 7: Chrome 109 وFirefox ESR 115.
  • لم يعد Windows 7 يتلقى تحديثات أمنية: أبقِ هذه الحواسيب في شبكة القاعة، ويُفضَّل دون وصول مباشر إلى الإنترنت.

2حاسوب الأستاذ

  1. شغّل برنامج التثبيت على حاسوب الأستاذ مع كل المكونات.
  2. في النهاية، اترك خانة تشغيل Tafat Master الآن محددة وانقر إنهاء.
هذا كل شيء: ينشئ برنامج التثبيت مفتاح الأستاذ ويضبط التوثيق. يبقى المفتاح الخاص على هذا الحاسوب، والمفتاح العمومي وحده ينتقل إلى حواسيب التلاميذ.

لتغيير اللغة: Tafat Master ← الإعدادات ← عام ← اللغة (العربية أو الفرنسية أو الأمازيغية بالحروف اللاتينية أو تيفيناغ أو الإنجليزية)، ثم موافق.

3حواسيب التلاميذ

  1. في Tafat Master، انقر برنامج تثبيت التلاميذ. إذا كانت في القاعة حواسيب بنظام Windows 7/8.1 أو 32 بت، انقر إضافة برنامج تثبيت… واختر الملف المناسب (الخطوة 1).
  2. أدخل مفتاح USB، وانقر إنشاء على مفتاح USB أو في مجلد… واختر المفتاح. يُكتب عليه مثلًا Install Tafat - student (Windows 10-11 64-bit).exe.
  3. على كل حاسوب تلميذ: انقر نقرًا مزدوجًا على هذا الملف، وأجب بـنعم عندما يطلب Windows الإذن، ثم التالي وتثبيت وإنهاء.
يحتوي برنامج تثبيت التلاميذ على المفتاح العمومي وإعدادات حاسوب الأستاذ: لا شيء آخر يلزم ضبطه على حواسيب التلاميذ. أعد إنشاءه إذا تغيّر حاسوب الأستاذ.

4إضافة الحواسيب إلى القاعة

  1. شغّل حواسيب التلاميذ.
  2. في Tafat Master، انقر إضافة حواسيب. أعطِ القاعة اسمًا، مثلًا قاعة الإعلام الآلي 1.
  3. انقر بحث: تظهر الحواسيب المثبَّت عليها تافات بعد بضع ثوانٍ. لشبكة أخرى، اكتبها في خانة الشبكة المراد البحث فيها (مثلًا 192.168.2.0/24)، أو أضف حاسوبًا باسمه أو بعنوان IP.
  4. حدّد حواسيب هذه القاعة، وانقر إضافة إلى القاعة وأجب بـنعم على Windows. تظهر الحواسيب فورًا في Tafat Master.
متقدّم: التثبيت الصامت وسطر الأوامر

لأدوات النشر، يعمل برنامج تثبيت التلاميذ أيضًا بصمت: "Install Tafat - student (Windows 10-11 64-bit).exe" /S. وتقبل برامج التثبيت العادية هذه الخيارات:

tafat-<version>-win64-setup.exe /S /NoMaster /ApplyConfig=D:\tafat-config.json /ImportPublicKey=D:\teacher_public_key.pem

سطر الأوامر (في موجّه أوامر بصلاحيات المسؤول):

"C:\Program Files\Tafat\tafat-cli.exe" labsetup setupteacher

إلغاء التثبيت: "C:\Program Files\Tafat\uninstall.exe" /S (أضف /ClearConfig لحذف الإعدادات أيضًا).

5التحقق

  1. في Tafat Master، يجب أن تعرض خانة كل حاسوب مشغَّل شاشةَ التلميذ.
  2. حدّد كل الحواسيب ثم الجرد: يجب أن يجيب كل حاسوب بالإصدار المتوقع (إصدارات الأنظمة القديمة مُعلَّمة). تصدير CSV… يحفظ القائمة.
  3. جرّب قفل ثم افتح القفل.

  • العناوين الثابتة أو حجوزات DHCP تجعل قائمة القاعة موثوقة.
  • خيار حظر الإنترنت أيضًا على جميع البرامج الأخرى يحظر عناوين الإنترنت العامة فقط: تبقى شبكة القاعة تعمل.
  • حظر الطباعة يوقف خدمة التخزين المؤقت للطباعة على حواسيب التلاميذ طوال الوضع، ثم تعود بعده.

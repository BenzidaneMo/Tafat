# Tafat artwork

Vector sources of the Tafat logo and icons, drawn with the colors of the
Tafat theme (`core/src/BrandTheme.h`).

| File | Use |
|---|---|
| `tafat-logo.svg` | Main logo: a T giving light to three student laptops |
| `tafat-logo-dark.svg` | Main logo for dark backgrounds |
| `tafat-master.svg` | Master app icon, 48 px and larger |
| `tafat-master-small.svg` | Master app icon, 16–32 px (window, tray) |
| `tafat-configurator.svg` | Configurator app icon, 48 px and larger |
| `tafat-configurator-small.svg` | Configurator app icon, 16–32 px |
| `tafat-splash.svg` | Splash screen of the master app (uses the Noto Sans Tifinagh font from `core/resources/fonts`) |
| `feature-*.svg` | Toolbar and tile icons: the Tafat features (application and website control, quiz, register, hand raise and chat, …) and the redrawn upstream ones (monitoring, demo, lock, remote view/control, power, log in/off, text message, start application, open website, distribute, collect, screenshot) |
| `panel-*.svg`, `button-*.svg` | Bottom-bar panel buttons and small buttons of the master; `-dark` variants use cream strokes for the dark theme |

The upstream icons, `panel-*` and `button-*` are generated by
`tools/generate-toolbar-icons.py artwork` (shared colors, stroke width and screen
shape); edit that script rather than the SVGs. `tools/render-artwork.sh` maps
them to the upstream PNG names (list at its end).

After changing a source file, run `tools/render-artwork.sh` (needs
`rsvg-convert` and ImageMagick). It regenerates the PNG, ICO, XPM and BMP
files used by the build, the Linux desktop integration and the Windows
installer. The generated files keep their upstream Veyon file names, so the
build system does not need to change.
